# 后续来源版本留存与实际复核人员读取

replaceMaintenanceReportEntries删除批次当前条目并新增、version+1，原条目身份不会长期留在当前表。独立结果仍可保留已生成来源身份，但不能仅凭当前表重建旧条目；不得从结果JSON身份猜测或回填已丢历史。后续需在版本替换边界保留经原事务授权的来源快照和版本，把已知旧来源/未知旧历史明确区分，不能将缺失当0。

maintenanceReviewTask/maintenanceReviewTaskPayloads仍从原maintenance_assignments读取实际参与人。下一阶段先固定“正式派工人不同于实际报工人”的复核读回、范围、资格和授权修改用例，再接独立实际参与来源。当前唯一结果匹配仅解决同人员工种、不同结果ID，不将别人的结果转给当前派工人。

例行原提报批次与复核后有效实际来源应并存，不回推原锁定批次。非例行已认定角色、不可变补记及已确认身份更正另有源通道和回执，不随普通结果适配器重建。全部来源确认、视图、门槛和确认重试一致后，才停止原正式提报/复核对派工的更新。
