# 例行正式派工与实际报工分离

源码核对确认正式例行提交与整体确认会替换正式派工，复核读取/重建也按派工，单独去掉提交写入会使后续复核记错人。新增原接口失败证据后联动调整：正式例行提报保留派工身份/来源，只推进原任务状态；整体确认比较原实际报工批次而非派工人员。例行提报不再隐式重派放行，变更正式放行归属须走独立派工操作。

任务树复核对flight读取有效routine/release批次，无批次历史仍原适配；授权人员修改实际参与人时修订对应报工批次版本，旧观察保留，生成新实际结果，不改正式派工。确认仍推进原任务及机会状态。原审核日志同时记录正式派工、实际参与人和批次版本，防止把二者混为一份身份。当前非例行仍原路径，未宣称完整分离。

新增真实路由链覆盖：root正式派工、另一实际例行人员提报、5小时原分配、整体完成、任务树读取、授权修订至第三人员、最终确认；每段派工身份/来源不变，原观察字节不变，新版本保留修订人。留存插入故障时复核原事实/结果/档案/日志整笔回滚；仅被列为实际参与人不获得派工报工资格；已确认后归档修改实际放行人，原派工身份保留且仍1架次。原独立结果身份/姓名快照专项继续通过。
