# 正式组织目录可维护改造

2026-09-04，已部署到8788独立测试服务。未操作8787。

## 使用入口

人员与能力 → 主数据管理 → 后台设置 → 正式组织目录。

- 预置组织可修改名称，人员分组可修改“参与维修调配”；修改须填写原因。
- 类型、父级不可改变；预置组织不可删除，自建组织须无引用才能删除。
- 组织代码不再对外显示或接受输入，新增时后台生成；已有组织ID及代码保留。
- 关闭调配时检查未归档、未确认派工及当前工作班组状态，存在引用则拒绝。
- 沿用组织维护权限、人员模块全部范围及关联账户会话撤销规则。

## 关联和导入

- 能力计算保留原内部班组键，通过稳定组织身份映射到当前显示名称；改名不转移人员、不改变RBAC或历史快照。
- 四个固定调配栏位不自动扩展为新组织；当前统计、图表、调配候选和报表使用目录名称。
- 批量开户指定范围使用完整中文路径，例如“指定行政班组:航线维修车间 / 二车间 / 一组”。保存后仍使用组织ID。
- 旧组织代码、缺失路径、歧义或类型错误整批拒绝；组织改名后旧文件路径需更新。
- 授权项目代码、角色代码和工号不在本次隐藏范围。
